# Bitácora de Hipertrofia

App web instalable (PWA) para entrenar hipertrofia con evidencia: programa por mesociclos, registro de series con progresión automática, nutrición que se calibra con tu peso real y sincronización opcional entre dispositivos vía un gist privado de GitHub.

Funciona sin conexión. Tus datos se guardan en cada dispositivo; este repositorio solo contiene la app.

## Instalar
- **Android (Chrome):** abre la URL → «Instalar» (o menú ⋮ → Instalar app).
- **iPhone / iPad (Safari):** Compartir → Agregar a pantalla de inicio.
- **Windows (Edge o Chrome):** ícono de instalar en la barra de direcciones (Edge: ⋯ → Aplicaciones → Instalar este sitio como aplicación).

## Publicar cambios
Todos los archivos van en la raíz del repositorio (sin carpetas), así que se suben de una vez desde el celular o la PC: Add file → Upload files → elige todos → Commit changes. Las apps instaladas muestran «Nueva versión disponible» y se actualizan con un toque.
